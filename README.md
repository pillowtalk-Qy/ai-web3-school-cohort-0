# AI x Web3 School Cohort 0

This repository records my learning journey for AI x Web3 School Cohort 0.

It is used for personal learning logs, task proofs, experiments, daily check-in drafts, Handbook feedback, and Hackathon preparation.

## About AI x Web3 School

AI x Web3 School is an open learning program for builders exploring the intersection of AI agents, wallets, signatures, smart contracts, identity, payments, governance, security, and verifiable records.

Useful links:

- Handbook: https://aiweb3.school/zh/handbook/
- Learning Agent prompt: https://aiweb3.school/learning-agent.zh.txt

## Learning Profile

I have some prior experience with both AI and Web3, but I am intentionally following this cohort from the beginning.

The goal is not to skip ahead quickly. The goal is to rebuild the foundation, identify gaps, follow the training rhythm, and keep a visible record of learning, experiments, and feedback.

## Directory Guide

- `daily/`: Daily learning notes and public check-in drafts.
- `tasks/`: Course tasks, proofs, links, and reflections.
- `experiments/`: Small AI x Web3 experiments and technical notes.
- `handbook-feedback/`: Feedback, questions, and improvement suggestions for the Handbook.
- `hackathon/`: Hackathon ideas, problem statements, demo plans, and project drafts.
- `submissions/`: Finalized submission materials and public proof summaries.
- `templates/`: Reusable note templates for daily logs, tasks, experiments, feedback, and Hackathon ideas.

## Privacy Reminder

This is intended to be a public repository. Do not commit private keys, seed phrases, API keys, access tokens, cookies, real-asset wallet details, private screenshots, or sensitive personal information.

For public experiments, prefer testnets and burner wallets. If a secret is committed, assume it has been compromised and rotate it immediately.

See `PRIVACY.md` for the full safety boundary.
