# Hackathon

This directory is for Hackathon preparation.

Use it for:

- Idea exploration
- Problem statements
- Target users
- AI component design
- Web3 component design
- MVP scope
- Demo plan
- Risks and unknowns
- Pitch drafts

Keep early ideas high-level until they are ready to publish.

Use `templates/hackathon-idea.md` when starting a new idea note.
