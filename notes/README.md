# Notes

This directory stores collected and organized external learning materials.

It is for class notes, meeting summaries, videos, articles, threads, documentation, repos, and mixed daily collections.

These notes may include AI-assisted summaries or external information整理. They are not always fully original writing, and they are not automatically verified facts.

## Structure

```text
notes/
├── daily-collections/
├── classes/
├── meetings/
└── topics/
```

## Directory Guide

- `daily-collections/`: Mixed external materials collected on a specific day.
- `classes/`: Course or live-class notes.
- `meetings/`: Community calls, weekly meetings, and event notes.
- `topics/`: Cross-day topic notes distilled from multiple sources.

## Verification Labels

Use one of these labels in each note:

- `raw`: Captured but not organized.
- `summarized`: Organized into sections.
- `reviewed`: Read and checked by the learner.
- `verified`: Key claims checked against direct sources.

## Privacy and Attribution

- Do not include private course materials if they are not meant to be public.
- Do not paste private chat logs or non-public transcripts.
- Prefer summaries over long verbatim excerpts.
- Mark whether a note is based on direct sources, secondary sources, or personal meeting notes.
- Add links to public sources when available.
