## 当前关注问题

### Agent Wallet 权限模型

Spending Limits、Session Keys、MPC、Account Abstraction 和人类确认这些机制如何组合？

How can spending limits, session keys, MPC, account abstraction, and human confirmation work together?

What should a truly personal-sovereign Agent Wallet look like if it needs to keep user control while hiding key-management and security-rule complexity?

### AI Agent 执行安全

在 Agent 调用合约、授权资产、跨链转移资金或签名交易之前，应该进行哪些风险检查？

What risk checks should happen before an Agent calls a contract, approves assets, bridges funds, or signs a transaction?

How should an Agent decide between continuing, pausing, blocking, or asking for human confirmation when risk signals are unclear?

### 个人可控的 AI x Web3 系统

AI Agent、钱包、身份、数据、记忆层、工具层和开源协作能否组合成一个可验证、可迁移、可退出的数字系统？

Can AI Agents, wallets, identity, data, memory layers, tool layers, and open-source collaboration form a verifiable, portable, and exit-capable digital system?

What roles do transaction simulation, risk detection, privacy protection, TEE, and intent routing each play in that system?

### Builder 路径

一个新 builder 如何从学习笔记走向 demo，从 demo 走向贡献，再从贡献走向可持续项目？

How can a new builder move from learning notes to demos, from demos to contributions, and from contributions to sustainable projects?

What kinds of public proof, experiments, and open-source participation help turn learning into visible builder credibility?
